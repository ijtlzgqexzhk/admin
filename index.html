ຕົວແທນຂາຍ

ລາຄາທີ່ປັບໃນໜ້າຕົວແທນ ມີຜົນສະເພາະເວັບຂອງຕົວແທນນັ້ນ. ລາຄາຫຼັກຂອງແອດມິນ ແລະ ລູກຄ້າທົ່ວໄປບໍ່ປ່ຽນ.

ຊື່ຜູ້ໃຊ້ອີເມວເບີໂທວັນທີສະໝັກສະຖານະຈັດການ

ຈັດການອໍເດີ

ອໍເດີ IDຜູ້ຊື້ສິນຄ້າຍອດສະຖານະຈັດການ

ກວດສະລິບເຕີມເງິນ

ລູກຄ້າແຈ້ງເຕີມເງິນແລ້ວຈະຂຶ້ນທີ່ນີ້ (ມີຫຼາຍຄົນກົດພ້ອມກັນກໍ່ເຫັນທຸກຄົນ). ກົດ ຢືນຢັນ ຫຼື ປະຕິເສດ ແລ້ວລາຍການນັ້ນຈະຫາຍໄປເລີຍ ບໍ່ສະແດງອີກ ຈົນກວ່າຈະມີລູກຄ້າໃໝ່ແຈ້ງເຂົ້າມາ.

ກວດປະຫວັດເຕີມເງິນ

ກວດວ່າລູກຄ້າຄົນໃດເຕີມເງິນຈັກຄັ້ງ ພ້ອມເວລາ ວັນ ເດືອນ ປີ. ຄົ້ນຫາດ້ວຍເບີໂທ ຫຼື ຊື່ຜູ້ໃຊ້. ຖ້າເວັ້ນຊ່ອງຄົ້ນຫາໄວ້ ຈະສະຫຼຸບລູກຄ້າທຸກຄົນທີ່ເຕີມໃນວັນທີ່ເລືອກ.

ເຕີມ / ຫັກເງິນ ດ້ວຍເບີໂທ

ໃສ່ເບີລູກຄ້າ ແລ້ວກົດຄົ້ນຫາ ຈະເຫັນຍອດເງິນເກົ່າ ກ່ອນເຕີມ ຫຼື ຫັກ (ສະເພາະແອັດມິນ)

ໂຄດເຕີມເງິນ

ສ້າງໂຄດໃໝ່

ລະບົບຈະສຸ່ມໂຄດໃຫ້ເອງ. ຜູ້ໃຊ້ແຕ່ລະຄົນໃຊ້ໂຄດດຽວກັນໄດ້ພຽງ 1 ຄັ້ງ.

ໂຄດຈຳນວນເງິນໃຊ້ແລ້ວ / ຈຳກັດສະຖານະວັນທີສ້າງຈັດການ

ຕັ້ງຄ່າ QR ຮັບຊຳລະເງິນ

ຮູບ QR Code

ອັບໂຫຼດຮູບ QR Code ຂອງແອດມິນ (ເຊັ່ນ BCEL One, LDB, ONEPAY) ເພື່ອໃຫ້ລູກຄ້າສະແກນຊຳລະເງິນ

ຍັງບໍ່ມີ QR

QR ແຍກຕາມຈຳນວນເງິນ

ຖ້າອັບໂຫຼດ QR ສຳລັບຈຳນວນໃດ, ລູກຄ້າທີ່ເລືອກຈຳນວນນັ້ນຈະເຫັນ QR ສະເພາະຂອງຈຳນວນນັ້ນ. ຖ້າບໍ່ອັບໂຫຼດ ຈະໃຊ້ QR ຫຼັກ.

ຕັ້ງຄ່າພື້ນຫຼັງເວັບ

ອັບໂຫຼດຮູບພື້ນຫຼັງເພື່ອນຳໃຊ້ທົ່ວທັງເວັບໄຊ (ຈະເປັນຄື fixed background ຢູ່ດ້ານຫຼັງຂອງທຸກອົງປະກອບ). ຖ້າຕ້ອງການໂພສຮູບແບນເນີໂຄສະນາ (ເຊັ່ນ Free Fire) ໃຫ້ໄປທີ່ໜ້າ "ແບນເນີ Hero" ແທນ.

ຍັງບໍ່ມີພື້ນຫຼັງ (ໃຊ້ຄ່າເລີ່ມຕົ້ນ)

ໂລໂກ ແລະ ຊື່ເວັບ

ປ່ຽນໂລໂກ ແລະ ຊື່ຮ້ານທີ່ສະແດງຢູ່ໜ້າເວັບ. ຖ້າບໍ່ອັບໂຫຼດໂລໂກ, ລະບົບຈະໃຊ້ໄອຄອນເລີ່ມຕົ້ນ.

ແບນເນີ Hero (ໜ້າຫຼັກ)

ອັບໂຫຼດຮູບແບນເນີໂຄສະນາ ຮູບນີ້ຈະສະແດງເປັນພື້ນຫຼັງຂອງສ່ວນ Hero ຢູ່ເທິງສຸດຂອງໜ້າຫຼັກ ໂດຍມີເງົາມືດຄຸມ. ແນະນຳຮູບແນວນອນ ຄວາມລະອຽດສູງ.

ຍັງບໍ່ມີແບນເນີ

ຂໍ້ຄວາມແລ່ນໂປຣໂມຊັນ

ແຖບທີ 1

ຂໍ້ຄວາມນີ້ຈະແລ່ນຢູ່ເທິງສຸດຂອງທຸກໜ້າ. ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ແຖບທີ 2 (ຢູ່ເທິງສຸດ, ແຍກຕ່າງຫາກຈາກແຖບທີ 1)

ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ວົງລໍສິນຄ້າ

ເລືອກສິນຄ້າທີ່ຢູ່ໃນວົງລໍ ແລະ ໃສ່ "ນ້ຳໜັກ" (ເລກຍິ່ງຫຼາຍ ໂອກາດຍິ່ງສູງ). ເປີເຊັນທີ່ຄຳນວນໄດ້ສະແດງຢູ່ຂ້າງແຖວ (ລູກຄ້າເຫັນກໍຕໍ່ເມື່ອຕິກ "ສະແດງ" ດ້ານເທິງ). ຕົວເລືອກທີ່ລູກຄ້າໄດ້ຮັບ = ຕົວເລືອກລາຄາຖືກສຸດທີ່ຍັງມີສະຕັອກ.

ຊ່ອງພິເສດ (ບໍ່ມີສິນຄ້າ ເຊັ່ນ ❌ ໂຊກດີຄັ້ງຕໍ່ໄປ) — ສະແດງໃນວົງລໍ ແຕ່ລູກຄ້າບໍ່ໄດ້ສິນຄ້າ

ແຈ້ງເຕືອນເຟສບຸກ (CallMeBot)

ເມື່ອລູກຄ້າແຈ້ງເຕີມເງິນ, ລະບົບຈະສົ່ງຂໍ້ຄວາມແຈ້ງເຕືອນເຂົ້າ Facebook Messenger ຂອງທ່ານໂດຍອັດຕະໂນມັດ (ຜ່ານ CallMeBot) ເຖິງແມ່ນວ່າແອດມິນຈະບໍ່ຢູ່ໜ້າເວັບກໍ່ຕາມ.

ວິທີເອົາ API Key: ເປີດ Messenger, ຄົ້ນຫາ ແລະ ແຊັດກັບ Callmebot → ພິມ create apikey → ມັນຈະສົ່ງ API Key ກັບມາ, ຄັດລອກມາໃສ່ຊ່ອງລຸ່ມນີ້.

ຈຳນວນນີ້ຈະສະແດງເປັນ "ເຫຼືອ X ອັນ" ໃຫ້ລູກຄ້າເຫັນ. (ຖ້າທຸກຕົວເລືອກມີລະຫັດສະຕັອກແລ້ວ ລະບົບຈະນັບຈຳນວນລະຫັດໃຫ້ເອງ)

ຖ້າເພີ່ມຕົວເລືອກຢ່າງໜ້ອຍ 1 ລາຍການ, ລູກຄ້າຈະຕ້ອງເລືອກກ່ອນຊື້ ແລະ ລາຄາ "ຫຼັກ" ດ້ານເທິງຈະບໍ່ຖືກໃຊ້ (ໃຊ້ລາຄາຂອງແຕ່ລະຕົວເລືອກແທນ). ແຕ່ລະຕົວເລືອກໃສ່ ມື້, ລາຄາ ແລະ ຂໍ້ມູນທີ່ລູກຄ້າຈະໄດ້ຮັບໄດ້ (ຖ້າບໍ່ໃສ່ຂໍ້ມູນຂອງຕົວເລືອກ ຈະໃຊ້ຂໍ້ມູນຫຼັກດ້ານລຸ່ມແທນ). ປະຫວ່າງໄວ້ຖ້າສິນຄ້ານີ້ມີລາຄາດຽວ.

ລະບົບຈະຫຍໍ້ຮູບໃຫ້ອັດຕະໂນມັດ ແລະສະແດງເຕັມຮູບ ບໍ່ຕັດຂອບ ສ່ວນທີ່ຫວ່າງຈະເຕີມດ້ວຍພື້ນຫຼັງເບລີຮູບດຽວກັນ
