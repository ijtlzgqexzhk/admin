ຈັດການສິນຄ້າ

ຮູບຊື່ໝວດລາຄາສະຕັອກສະຖານະວັນທີຈັດການ

ຈັດການຜູ້ໃຊ້

ຊື່ຜູ້ໃຊ້ອີເມວເບີໂທວັນທີສະໝັກສະຖານະຈັດການ

ຈັດການອໍເດີ

ອໍເດີ IDຜູ້ຊື້ສິນຄ້າຍອດສະຖານະຈັດການ

ກວດສະລິບເຕີມເງິນ

ລູກຄ້າແຈ້ງເຕີມເງິນແລ້ວຈະຂຶ້ນທີ່ນີ້ (ມີຫຼາຍຄົນກົດພ້ອມກັນກໍ່ເຫັນທຸກຄົນ). ກົດ ຢືນຢັນ ຫຼື ປະຕິເສດ ແລ້ວລາຍການນັ້ນຈະຫາຍໄປເລີຍ ບໍ່ສະແດງອີກ ຈົນກວ່າຈະມີລູກຄ້າໃໝ່ແຈ້ງເຂົ້າມາ.

ກວດປະຫວັດເຕີມເງິນ

ກວດວ່າລູກຄ້າຄົນໃດເຕີມເງິນຈັກຄັ້ງ ພ້ອມເວລາ ວັນ ເດືອນ ປີ. ຄົ້ນຫາດ້ວຍເບີໂທ ຫຼື ຊື່ຜູ້ໃຊ້. ຖ້າເວັ້ນຊ່ອງຄົ້ນຫາໄວ້ ຈະສະຫຼຸບລູກຄ້າທຸກຄົນທີ່ເຕີມໃນວັນທີ່ເລືອກ.

ເຕີມ / ຫັກເງິນ ດ້ວຍເບີໂທ

ໃສ່ເບີລູກຄ້າ ແລ້ວກົດຄົ້ນຫາ ຈະເຫັນຍອດເງິນເກົ່າ ກ່ອນເຕີມ ຫຼື ຫັກ (ສະເພາະແອັດມິນ)

ຕັ້ງຄ່າ QR ຮັບຊຳລະເງິນ

ຮູບ QR Code

ອັບໂຫຼດຮູບ QR Code ຂອງແອດມິນ (ເຊັ່ນ BCEL One, LDB, ONEPAY) ເພື່ອໃຫ້ລູກຄ້າສະແກນຊຳລະເງິນ

ຍັງບໍ່ມີ QR

QR ແຍກຕາມຈຳນວນເງິນ

ຖ້າອັບໂຫຼດ QR ສຳລັບຈຳນວນໃດ, ລູກຄ້າທີ່ເລືອກຈຳນວນນັ້ນຈະເຫັນ QR ສະເພາະຂອງຈຳນວນນັ້ນ. ຖ້າບໍ່ອັບໂຫຼດ ຈະໃຊ້ QR ຫຼັກ.

ຕັ້ງຄ່າພື້ນຫຼັງເວັບ

ອັບໂຫຼດຮູບພື້ນຫຼັງເພື່ອນຳໃຊ້ທົ່ວທັງເວັບໄຊ (ຈະເປັນຄື fixed background ຢູ່ດ້ານຫຼັງຂອງທຸກອົງປະກອບ). ຖ້າຕ້ອງການໂພສຮູບແບນເນີໂຄສະນາ (ເຊັ່ນ Free Fire) ໃຫ້ໄປທີ່ໜ້າ "ແບນເນີ Hero" ແທນ.

ຍັງບໍ່ມີພື້ນຫຼັງ (ໃຊ້ຄ່າເລີ່ມຕົ້ນ)

ຮູບ / ວິດີໂອ ສອນເຕີມເງິນ

ອັບໂຫຼດຮູບສອນວິທີເຕີມເງິນ. ເມື່ອລູກຄ້າກົດເຂົ້າບ່ອນເຕີມເງິນ (ກະເປົາເງິນ) ຈະເຫັນຮູບນີ້ເຕັມຈໍທັນທີ ແລະ ມີປຸ່ມ ✕ ປິດ.

ຍັງບໍ່ມີຮູບສອນເຕີມເງິນ

ວິດີໂອສອນເຕີມເງິນ (YouTube)

ວາງລິ້ງ YouTube. ເມື່ອລູກຄ້າກົດເຂົ້າບ່ອນເຕີມເງິນ ວິດີໂອຈະເດັ່ງຂຶ້ນກາງໜ້າຈໍເວັບທັນທີ ແລະ ມີປຸ່ມ ✕ ປິດ. ຖ້າມີທັງວິດີໂອ ແລະ ຮູບ ຈະສະແດງວິດີໂອກ່ອນ ແລ້ວຮູບຢູ່ລຸ່ມ.

ປຸ່ມລິ້ງ (ຢູ່ເທິງສຸດໜ້າ ລົງຊື່ເຂົ້າໃຊ້)

ຕັ້ງຊື່ປຸ່ມ ແລະ ລິ້ງ. ເມື່ອລູກຄ້າກົດບ່ອນ ລົງຊື່ເຂົ້າໃຊ້ (ເຂົ້າສູ່ລະບົບ / ສະໝັກສະມາຊິກ) ປຸ່ມນີ້ຈະສະແດງຢູ່ເທິງສຸດຂອງໜ້າທັນທີ ແລະ ເປີດລິ້ງໃນແຖບໃໝ່. ບໍ່ໃສ່ = ບໍ່ສະແດງປຸ່ມ.

ເພງພື້ນຫຼັງເວັບ

ເພີ່ມເພງໄວ້ຫຼາຍເພງ ແລ້ວກົດ "ເລືອກ" ເພງທີ່ຕ້ອງການໃຫ້ລູກຄ້າຟັງ. ທຸກຄັ້ງທີ່ລູກຄ້າເຂົ້າເວັບ ເພງຈະເລີ່ມຫຼິ້ນໃໝ່ ແລະ ວົນຕະຫຼອດ (ລູກຄ້າມີປຸ່ມປິດ/ເປີດເພງເອງ). ລະບົບຈະບີບອັດເພງໃຫ້ອັດຕະໂນມັດ (MP3 mono 64kbps) ກ່ອນອັບໂຫຼດ — ເລືອກໄຟລ໌ໄດ້ສູງສຸດ 40MB, ຫຼັງບີບອັດຕ້ອງບໍ່ເກີນ 6MB. ຖ້າຍາວຫຼາຍໃຫ້ວາງລິ້ງເພງແທນ.

ຕັ້ງຄ່າບັນຊີຮັບເງິນ

ຕັ້ງຊື່ບັນຊີຮັບເງິນຂອງຮ້ານ. ເມື່ອລູກຄ້າອັບໂຫຼດສະລິບ ລະບົບຈະອ່ານສະລິບ ແລະ ເຕີມຊື່ຜູ້ໂອນ + ເວລາໂອນໃຫ້ອັດຕະໂນມັດ ຈາກນັ້ນກວດ ຊື່ຜູ້ຮັບ, ເວລາ, ວັນທີ, ຈຳນວນເງິນ ແລະ ເລກອ້າງອີງ (ກັນສະລິບຊ້ຳ). ຖືກຕ້ອງທຸກຢ່າງ → ເຕີມເງິນໃຫ້ອັດຕະໂນມັດຫຼັງ ~10 ວິ. ບໍ່ຖືກ / ສະລິບບໍ່ຊັດ / ສະລິບເກົ່າ (ມື້ວານ) / ສະລິບຊ້ຳ → ປະໄວ້ໃຫ້ແອັດມິນກວດເອງໃນແທັບ "ກວດສອບເຕີມເງິນ" (ລູກຄ້າບໍ່ເຫັນວ່າຖືກປະຕິເສດ).

* ຖ້າບໍ່ໃສ່ຊື່ບັນຊີ ຫຼື ປິດໃຊ້ງານ ລະບົບຈະສົ່ງສະລິບໃຫ້ແອັດມິນກວດເອງແບບເດີມ. ຖ້າລະບົບອ່ານສະລິບບໍ່ຄົບ ກໍຈະສົ່ງໃຫ້ແອັດມິນກວດເຊັ່ນກັນ. ລະບົບກວດ: ຈຳນວນເງິນ, ວັນທີ/ເວລາ (ຕ້ອງເປັນມື້ນີ້ ແລະ ຫຼັງເປີດ QR), ເລກອ້າງອີງ/ເລກໃບບິນ (ກັນຊ້ຳ), ຊື່ຜູ້ຮັບ.

ໂລໂກ ແລະ ຊື່ເວັບ

ປ່ຽນໂລໂກ ແລະ ຊື່ຮ້ານທີ່ສະແດງຢູ່ໜ້າເວັບ. ຖ້າບໍ່ອັບໂຫຼດໂລໂກ, ລະບົບຈະໃຊ້ໄອຄອນເລີ່ມຕົ້ນ.

ແບນເນີໜ້າຫຼັກ (ເລື່ອນໄດ້)

ອັບໂຫຼດໄດ້ຫຼາຍຮູບ (ສູງສຸດ 8 ຮູບ). ແບນເນີຈະສະແດງຢູ່ເທິງໜ້າຫຼັກ ລູກຄ້າກົດລູກສອນຊ້າຍ/ຂວາ ຫຼື ປັດນິ້ວເພື່ອເບິ່ງຮູບຕໍ່ໄປ ແລະ ເລື່ອນເອງອັດຕະໂນມັດ. ແນະນຳຮູບແນວນອນ ສັດສ່ວນ 2:1 (ເຊັ່ນ 1200×600).

ເລືອກຮູບແລ້ວ ກົດ "ບັນທຶກແບນເນີ" ເພື່ອໃຫ້ລູກຄ້າເຫັນ. ໃຊ້ປຸ່ມ ▲ ▼ ປ່ຽນລຳດັບ.

ວິທີລົງຄ່າ / ລົງໄຟລ໌

ກ່ອງນີ້ລູກຄ້າຈະເຫັນຢູ່ເທິງສຸດຂອງໜ້າ "ລາຍການຊື້ສຳເລັດ" ໃຊ້ສອນວິທີລົງຄ່າ / ລົງໄຟລ໌. ຖ້າບໍ່ໃສ່ຫຍັງ ຈະສະແດງຂໍ້ຄວາມເລີ່ມຕົ້ນໃຫ້ທັກແອດມິນ.

ຂໍ້ຄວາມແລ່ນໂປຣໂມຊັນ

ແຖບທີ 1

ຂໍ້ຄວາມນີ້ຈະແລ່ນຢູ່ເທິງສຸດຂອງທຸກໜ້າ. ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ແຖບທີ 2 (ຢູ່ເທິງສຸດ, ແຍກຕ່າງຫາກຈາກແຖບທີ 1)

ປະຫວ່າງໄວ້ຫວ່າງເພື່ອເຊື່ອງແຖບນີ້.

ແຈ້ງເຕືອນ (Facebook + ເດັ້ງໃນໂທລະສັບ)

ເມື່ອລູກຄ້າແຈ້ງເຕີມເງິນ, ລະບົບຈະສົ່ງຂໍ້ຄວາມແຈ້ງເຕືອນເຂົ້າ Facebook Messenger ຂອງທ່ານໂດຍອັດຕະໂນມັດ (ຜ່ານ CallMeBot) ເຖິງແມ່ນວ່າແອດມິນຈະບໍ່ຢູ່ໜ້າເວັບກໍ່ຕາມ.

ວິທີເອົາ API Key: ເປີດ Messenger, ຄົ້ນຫາ ແລະ ແຊັດກັບ Callmebot → ພິມ create apikey → ມັນຈະສົ່ງ API Key ກັບມາ, ຄັດລອກມາໃສ່ຊ່ອງລຸ່ມນີ້.
